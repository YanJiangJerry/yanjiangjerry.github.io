# Yan Jiang — Personal Website

Static personal homepage for [Yan Jiang](https://yanjiangjerry.github.io/).

## Local preview

```bash
cd Yan.github.io
python3 -m http.server 8080
```

Open http://localhost:8080

## Deploy to GitHub Pages

1. Push this repo to `yanjiangjerry.github.io`.
2. In repo **Settings → Pages**, set source to `main` branch, root `/`.
3. Site will be live at `https://yanjiangjerry.github.io/`.

## Customize

- Publications / teaching: edit `index.html`
